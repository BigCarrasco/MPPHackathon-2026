DEMO GUIDE

From stock to a paid quote.

01 Review restocking needs

Restocking lists the packs needed to reach each target. The initial inventory needs 40 bottles across four products.

02 Generate a quote

Click Generate quote. The supplier returns HTTP 402. The agent checks its policy, pays 0.01 test pathUSD on Tempo Testnet and receives prices with a receipt. No inventory is purchased.

03 Show the controls

Open Payment flow & receipt. Repeat the request to show the saved result without another payment. Pause Autopilot to demonstrate a blocked request.

04 Change the inventory

Record a sale in Menu and return to Restocking. Needs update automatically. Set stock targets in Ingredients. Reset demo fills stock and clears local sales; server spending records remain.
